🔐 Lavender 1.0.7.1: Секретные чаты (E2EE)

— Секретные чаты: Новый тип чата с сквозным шифрованием. Сообщения шифруются на устройстве отправителя и расшифровываются на устройстве получателя — сервер не может их прочитать.
— Обмен ключами: ECDH (Curve25519) для установки общего секрета между участниками.
— Шифрование: AES-256-GCM для всех сообщений секретного чата.
— Индикатор: Иконка замка и подпись "End-to-end encrypted" в шапке секретного чата.
— Создание: Новая кнопка "Secret Chat" в меню создания чата.
— Совместимость: Клиенты старше 1.0.7.1 не увидят сообщения секретных чатов.

🔐 Lavender 1.0.7.0: Безопасное хранение учётных данных

— Шифрование: Пароли теперь хранятся в EncryptedSharedPreferences с AES-256 шифрованием и аппаратным хранилищем ключей (KeyStore).
— Исправлено: Пароль больше не передаётся между экранами через Intent extras.
— Исправлено: Пароль исключён из данных push-уведомлений.
— Миграция: При первом запуске пароли автоматически переносятся из обычного хранилища в зашифрованное.
