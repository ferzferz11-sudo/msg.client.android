## Key Decisions

| Decision | Rationale |
|----------|-----------|
| Facade + inline delegates | Extension functions don't work via star import in Kotlin |
| MockK for tests | Mockito not in deps, MockK is Kotlin-native |
| ErrorHandler统一 | All errors through ErrorHandler → AppLog + Log |
| Chat delegates pattern | 6 delegates instead of monolithic NewChatActivity |
| Optimistic READY | gRPC channel connects lazily |
| Keepalive 30s/10s | For mobile networks |
| Poll 30s | Reduce server load |
