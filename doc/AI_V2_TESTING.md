# AI v2 — Сценарии тестирования

**Версия:** v1.3.0.0 | **Дата:** 2026-06-20

---

## Предусловия

1. Сервер запущен с AI v2 API (`messenger.AIService/*`)
2. JWT токен валиден
3. Клиент подключен к серверу
4. На сервере есть минимум 1 встроенный агент (presets)

---

## Фаза 1: Базовый стриминг (simple chat)

### T1.1 — Первое сообщение к пресет-агенту
**Шаги:**
1. Открыть чат с пресет-агентом `assistant`
2. Написать "Привет, кто ты?"
3. Отправить

**Ожидаемый результат:**
- Появляется индикатор typing
- Токены приходят по одному (стриминг)
- После завершения — полный ответ отображается
- `finished = true` в ответе
- Агент показывает имя "Assistant"

**Проверка:** ответ не пустой, нет ошибок

---

### T1.2 — Продолжение сессии (session_id)
**Шаги:**
1. Отправить сообщение в новый чат
2. Получить ответ
3. Отправить следующее сообщение в тот же чат

**Ожидаемый результат:**
- Сервер использует тот же `session_id`
- Агент помнит контекст предыдущего сообщения
- Ответ связан с предыдущим вопросом

---

### T1.3 — Выбор агента по agent_id
**Шаги:**
1. Отправить сообщение с `agent_id = "developer"`
2. Получить ответ

**Ожидаемый результат:**
- Ответ от агента Developer
- `agent_id` в response совпадает с запрошенным
- `agent_name` показывается в UI

---

## Фаза 2: Tool Calling

### T2.1 — Инструмент search_messages
**Шаги:**
1. Написать агенту `assistant`: "Найди сообщения с словом 'hello' в чате [chat_id]"
2. Дождаться ответа

**Ожидаемый результат:**
- Сервер отправляет `tool_calls` с `name = "search_messages"`
- Клиент получает tool_calls в `ChatWithAIV2Response`
- Сервер продолжает стриминг с результатом инструмента
- Финальный ответ содержит результат поиска

**Проверка:** агент ссылается на найденные сообщения

---

### T2.2 — Инструмент web_search
**Шаги:**
1. Написать агенту `assistant`: "Найди последние новости про Go 1.22"
2. Дождаться ответа

**Ожидаемый результат:**
- Сервер отправляет `tool_calls` с `name = "web_search"`
- Клиент пересылает результат обратно
- Агент использует результат в ответе

---

### T2.3 — Цепочка инструментов (multi-tool)
**Шаги:**
1. Написать: "Найди информацию о recent commits в репозитории X и найди веб-статьи про них"
2. Дождаться полного ответа

**Ожидаемый результат:**
- Сервер вызывает 2+ инструмента последовательно
- Каждый tool call обрабатывается клиентом
- Итерация не превышает 10 (MAX_TOOL_ITERATIONS)
- Финальный ответ агрегирует результаты

---

### T2.4 — Tool call failure (сервер вернул ошибку)
**Шаги:**
1. Написать запрос, который вызовет инструмент с невалидными параметрами
2. Дождаться ответа

**Ожидаемый результат:**
- Сервер отправляет `error` в response
- Клиент отображает ошибку
- Приложение не крашится

---

## Фаза 3: Agent CRUD

### T3.1 — Список пресет-агентов
**Шаги:**
1. Открыть AiV2AgentListActivity
2. Выбрать таб "Presets"

**Ожидаемый результат:**
- Отображается список встроенных агентов (assistant, developer, devops, architect, writer, analyst, translator, mimo)
- Каждый агент показывает: имя, провайдер, описание, модель
- Индикаторы tools/RAG если включены
- Кнопка удаления НЕ видна для пресетов

---

### T3.2 — Создание нового агента
**Шаги:**
1. Нажать FAB "+"
2. Заполнить форму:
   - Name: "My Test Agent"
   - Description: "Test agent for QA"
   - Provider: openrouter
   - Model: anthropic/claude-sonnet-4
   - System Prompt: "Ты тестовый агент"
   - Tools: включить
   - RAG: выключить
3. Нажать "Save"

**Ожидаемый результат:**
- Агент создан (сервер вернул `success = true`)
- Отображается toast "Agent saved"
- Экран закрыт
- В списке "My Agents" появился новый агент

---

### T3.3 — Редактирование агента
**Шаги:**
1. Открыть список агентов → "My Agents"
2. Нажать на агента "My Test Agent"
3. Изменить Description на "Updated description"
4. Нажать "Save"

**Ожидаемый результат:**
- Агент обновлён
- В списке видно новое описание

---

### T3.4 — Удаление агента
**Шаги:**
1. Открыть список → "My Agents"
2. Нажать иконку удаления рядом с агентом
3. Подтвердить в диалоге

**Ожидаемый результат:**
- Диалог подтверждения: "Delete agent 'X'?"
- После подтверждения — агент удалён из списка
- Сервер вернул `success = true`

---

### T3.5 — Клонирование агента
**Шаги:**
1. Вызвать `AiV2ChatUseCase.cloneAgent("assistant", "My Assistant Clone")`

**Ожидаемый результат:**
- Новый агент создан с теми же настройками
- Имя: "My Assistant Clone"
- ID новый, отличный от оригинала

---

### T3.6 — Табы списка агентов
**Шаги:**
1. Открыть список агентов
2. Переключиться между табами Presets / My Agents / Public

**Ожидаемый результат:**
- Presets: показывает только встроенные агенты
- My Agents: показывает только пользовательские (не preset, не public)
- Public: показывает публичные агенты других пользователей

## Фаза 6: Edge cases

### T6.1 — Сервер недоступен
**Шаги:**
1. Отключить сервер
2. Попробовать отправить сообщение

**Ожидаемый результат:**
- Retry с exponential backoff (3s → 30s)
- После 10 попыток — ошибка "Connection lost after 10 attempts"
- Приложение не крашится

---

### T6.2 — Пустое сообщение
**Шаги:**
1. Попробовать отправить пустое сообщение

**Ожидаемый результат:**
- Кнопка отправки неактивна или сообщение не отправляется

---

### T6.3 — Timeout стриминга
**Шаги:**
1. Отправить сообщение, которое занимает >120с на обработку

**Ожидаемый результат:**
- Stream timeout: "Response timeout (120s). Please try again."
- Приложение не крашится

---

### T6.4 — Невалидный agent_id
**Шаги:**
1. Отправить сообщение с `agent_id = "nonexistent"`

**Ожидаемый результат:**
- Сервер вернёт ошибку
- Клиент отображает ошибку

---

### T6.5 — Множественные быстрые отправки
**Шаги:**
1. Отправить 3 сообщения подряд очень быстро

**Ожидаемый результат:**
- Все 3 сообщения обработаны
- Ответы приходят в правильном порядке
- UI не дёргается
