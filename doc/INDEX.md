## Правила документации

- При старте новой сессии: PROMPT_ANDROID.md → SESSION_NOTES.md → PATTERNS.md
- После каждого значимого изменения: обновлять SESSION_NOTES.md + PROMPT_ANDROID.md
- При каждом релизе: обновлять CHANGELOG.md, PROMPT_ANDROID.md (changelog + статус)
- SESSION_NOTES.md ≤ 200 строк → архивировать старые сессии
- Не создавать новые doc-файлы без крайней необходимости
